# Blog Management System

A modern full-stack Blog Management System with Admin Dashboard, Rich Text Editor, Category Filters, and Responsive Design.

---

# Features

## Admin Panel
- Secure Admin Login using JWT Authentication
- Create New Blogs
- Edit Existing Blogs
- Delete Blogs
- Rich Text Editor Support
- Add Blog Images
- Category Selection
- Real-time Blog Management

## Frontend
- Responsive Design for Mobile & Desktop
- Blog Listing Page
- Category Filters
- Blog Details Page
- Read More Functionality
- Clean Modern UI

---

# Tech Stack

## Frontend
- React.js
- Vite
- Tailwind CSS
- React Router DOM
- Axios
- React Quill

## Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcryptjs

## Deployment
- Vercel (Frontend)
- Render (Backend)
- MongoDB Atlas (Database)
